# 🎭 Task 2 - Random Joke Generator (API-Based Web App)

A simple and interactive web application that fetches random jokes from a public API and displays them in a clean, user-friendly interface.  
This project demonstrates how to consume REST APIs using JavaScript and present the data dynamically on a web page.

---

## 📌 Task Objective

To create a program that:
- Fetches data from a public API
- Parses the received response
- Displays the data in a readable and user-friendly format
- Handles different API responses correctly

## 🚀 Features

- Fetches a **random joke** from a public API
- Displays **setup and punchline** dynamically
- Clean and responsive UI
- No backend required
- No API key needed

- **HTML5** – Structure

**Official Joke API**

- Endpoint:
https://official-joke-api.appspot.com/random_joke

- Response Format: JSON
- Authentication: Not required

## ⚙️ How It Works

1. User clicks the **Get Joke** button
2. JavaScript sends a request using `fetch()`
3. The API returns a joke in JSON format
4. The setup and punchline are extracted
5. The joke is displayed on the webpage
